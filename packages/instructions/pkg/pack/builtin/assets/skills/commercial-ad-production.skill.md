# 商业广告幕后制作增强

## 作用边界

这是商业广告工作台的幕后检查层，不是新的前端流程。保持项目现有阶段、按钮、文档和生成接口不变；不得把用户带入另一套十阶段流程，也不得覆盖已经锁定的脚本、分镜、资产或人工选择。

开始前读取当前项目中与任务直接相关的已批准内容。区分三类信息：已确认事实、当前创作建议、真实生成/审核记录。建议不能悄悄改写事实，生成失败不能反过来篡改用户已确认的品牌要求。

若任务实际要提交图片或视频生成，完成本 Skill 的检查后，再分别装载 `image-generation` 或 `video-generation`；本 Skill 自身不选择 Provider、模型、API Key 或请求参数。

## 按任务增强

### 分镜与资产关系

- 每个镜头只承担一个清晰的传播或叙事任务，并有可判断的完成标准。
- 给镜头、产品、人物、服装、场景和关键道具使用稳定 ID；建立镜头到资产版本的关系。
- 记录场景锚点、产品位置、人物动线、轴线和屏幕方向。动作或信息超出合理时长时先拆镜，不靠堆砌 Prompt 解决。

### 资产制作与审核

- 把“身份不变量”和“本镜状态”分开：产品结构、包装、Logo、人物身份属于身份；角度、污渍、开合、手持物、情绪和服装状态属于版本。
- 每张参考说明 `inherit` 与 `exclude`：继承哪些身份、材质或风格信息，排除原图构图、机位、光线或无关元素。
- 未通过版本保留失败原因；只有批准版本才能进入正式镜头。产品结构、品牌文字和 Logo 准确性优先于氛围感。

### 单镜执行设计

每镜按需要覆盖以下七层，不要求把字段机械地全部输出：

1. 本镜意图与验收目标。
2. 使用的资产 ID、批准版本、当前状态和参考范围。
3. 主体数量、空间位置、遮挡、轴线与环境锚点。
4. 动作节拍、表演目标、物理因果和落定状态。
5. 起始构图、焦段/机位、主运镜、对焦、结束构图和切点。
6. 主光源、色彩、材质、环境声、对白与音效。
7. 必须保持、本镜允许变化、禁止出现、画幅/时长等交付约束。

明确 `open state` 与 `close state`；相邻镜头应让上一镜的 close state 能接到下一镜的 open state。Prompt 不得创建资产表中不存在的主要产品、人物、地点或关键道具。

### 生成失败诊断

先根据失败现象确定责任层：资产/参考、镜头契约、Prompt、模型能力、生成适配或后期。每轮只改变少量有理由的变量，并记录：失败现象、责任层、改动变量、修复假设、结果和下一步。

同一问题连续两个批次没有改善时，停止重复抽卡，返回资产版本、空间关系、镜头契约或拆镜处理。不要默认只增加负向词。

### 选片、粗剪与连续性

- 选择记录必须指向具体生成版本，并写明通过或淘汰原因；生成历史不等于正式选片。
- 依次检查产品/人物身份、状态、空间、轴线、屏幕方向、动作接点、光色和声音接点。
- 可接受缺陷必须记录影响、批准范围和后期修复方式，不能用口头“没关系”跳过质量门。
- 粗剪同时验证广告信息是否可读：开场吸引力、产品出现、卖点证明、品牌记忆、CTA 和总时长。

### 项目复盘

沉淀成功版本、失败模式、成本/重试次数、可复用 Prompt、批准资产和连续性规则。把已验证结论与下一轮假设分开；不要把单次偶然结果升级成永久规则。

## 输出方式

优先在用户当前操作所需的产物上直接增强，不额外制造一套管理文档。若发现会造成返工的冲突，明确指出冲突位置、影响镜头和最小修复建议；没有实质风险时继续当前工作，不用流程术语打断用户。

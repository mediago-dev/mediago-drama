# 20:15 实际使用反馈对应的工程验收清单

这份清单把真实使用链路转成可验收的产品行为。它不是新的工作流文档，而是本地桌面 App 的交付标准。

## P0：必须可用

- [x] “继续制作”直接进入当前阶段的工作文档或工作区，不再落到空的项目概览页。
- [x] 没有文档、资产、镜头或生成任务的阶段保持置灰；第一阶段可直接开始。
- [x] 上一阶段未通过时仍可进入，但必须展示返工风险。
- [x] 阶段同时展示自动判断、手动标注和最终生效状态。
- [x] 手动标注可以恢复为“跟随自动判断”，不会被旧兼容字段重新覆盖。
- [x] 图片 / 视频任务进入项目级任务列表，并参与阶段自动状态计算。
- [x] 生成任务失败会进入“需修改”并显示失败风险。
- [x] 生成成功后结果进入项目资产库，任务记录保留 Prompt、模型、参数、参考图和阶段信息。
- [x] 项目可以指定本地输出目录；桌面端会把可用的生成文件复制到该目录，原始项目媒体库不被删除或覆盖。
- [x] 切换阶段时仍复用同一项目上下文，不要求重新解释项目。
- [x] Intel macOS 启动入口会自动选择 x86_64 ACP，并补齐文档 MCP / 生成 MCP；制作助理运行配置检查返回 200。
- [x] 制作助理挂载项目文档 MCP 与生成 MCP，能读取当前项目上下文，而不是只启动一个孤立聊天进程。

## P1：应该完善

- [x] 工作序列进入真实制作工作台：阶段导航、当前阶段、交付清单、风险提示、执行入口和项目上下文集中在同一页。
- [x] 每个阶段提供“先分析—等确认—执行—审核”四步提示，确认前不触发批量生成。
- [x] 工作台分析、确认、执行、审核状态和当前阶段备注按项目配置保存，重启后可恢复；旧版 localStorage 会兼容读取。
- [x] QC、Blocker、版本和审核记录完整接入自动状态。阶段级 QC 的 PASS / NEEDS_FIX / BLOCKED / MISSING 会参与自动状态；人工标注仍可覆盖，但会明确显示自动判断。
- [x] 输出目录复制记录写入项目归档索引，支持跨重启去重和重新归档。去重键为 `taskId + assetId（或槽位）+ outputDirectory`，文件名会清理危险字符并补齐扩展名。
- [x] 生成任务中心提供按项目、阶段、文档和镜头筛选。
- [x] 参考图组保存角色（风格、姿势、构图、材质、灯光等），并写入项目配置供后续阶段复用。
- [x] 每个阶段有明确的“先分析—等待确认—再执行—进入审核”门槛；确认前执行入口置灰，审核结论会回写阶段状态。
- [x] 旧项目、无模板项目、缺失资产项目和异常任务都有可读的恢复提示。

## P2：商业化增强

- [x] 项目总控展示 Shot / Asset / QC / Version 的摘要和下一步行动。
- [x] 生成结果可按资产、镜头、阶段和版本自动命名并归档。
- [x] 复盘结论可沉淀为下一项目可复用的规则、Prompt 和案例。
- [ ] 提供完整的桌面端验收脚本，覆盖创建、生成、审核、归档、切换项目和重启恢复。
